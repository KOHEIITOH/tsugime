# つぎめ — 割れた思い出を、金で継ぐ

割れてしまった思い出を、金継ぎの工程どおりにゆっくり継いで、世界にひとつの器にする小さなWebアプリです。

https://koheiitoh.github.io/tsugime/

## 工程
1. **器をえらぶ** — 思い出に名札をつけ、器（茶碗・湯のみ・豆皿）と釉薬を選ぶ。いつ・どこでのことかも書ける。
2. **かけらを拾う** — 何があったか、どう感じたかを書くと、器にひびが入る。
3. **漆で継ぐ** — そこから得たもの、支えてくれたものを書くと、ひびが金の線に変わる。
4. **室で休ませる** — 1分間、呼吸に合わせて器を休ませる（省略もできる）。
5. **銘をつける** — 土地と季節のことばから名前をつけて棚に飾る。金は30日かけてなじむ。

完成した器は、銘と器の絵だけの画像（PNG）にして保存・共有できます。書いた文章は、チェックを入れたときだけ画像に入ります。

## プライバシー
- アカウント不要、サーバーなし、外部通信なし。
- データはブラウザの localStorage にだけ保存されます。棚の控え（JSON）を書き出して戻すこともできます。

## 構成
ビルド不要の静的サイトです（`index.html` / `style.css` / `app.js`）。GitHub Pages の main ブランチ / (root) からそのまま配信できます。
